# YapperLink

YapperLink is a Minecraft plugin designed to enhance player interaction by providing a simple command that sends a clickable link to the player's chat. This plugin is perfect for server owners who want to easily share important links with their players, such as forums, social media, or other resources. The link is fully customizable through the configuration file, allowing for easy updates without modifying the plugin code.

## Install

1. Download the YapperLink plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file into the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. Ensure the plugin is installed and the server is running.
2. Players can use the `/yapper` command to receive a clickable link in their chat.
3. The link can be customized by editing the `config.yml` file located in the `plugins/YapperPlugin` directory.
